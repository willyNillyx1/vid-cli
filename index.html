Features

Everything between the prompt and the player.

A focused tool, not a platform. Search, choose, play, download, and come back later — with plain files and no background services.

01

Search, pick, play

Results arrive as a clean fzf menu with title, channel, duration, views and upload date. The video ID stays hidden; ENTER sends your choice straight to the player.

vid-cli "lofi hip hop"
02

720p by default

Ask for 360, 480, 720, 1080, best or worst. yt-dlp resolves the stream and mpv plays it. Audio-only mode and VLC are one flag away.

-q 1080 · -a · -v
03

Playlists, one by one

Paste a video, playlist or channel URL. Multi-select up to 100 entries with TAB, then move through the queue with next, previous, replay and re-select.

TAB to mark · ENTER to play
04

Download or go audio-only

Save video or extract audio with yt-dlp. ffmpeg merges and converts when it is installed; single-file fallbacks keep downloads working without it.

-d · -d -a
05

History you can read

A plain TSV file, newest first, capped at 500 entries. Reopen anything with -c, inspect it with ordinary text tools, or use --no-history for a private session.

-c · --no-history
06

Anime without scrapers

AniList supplies synopsis, studio, genres, next airing time, trailers and official episode links. Licensed services open in your browser, on their own terms.

--anime "Cowboy Bebop"

The whole loop

  1. 01 · ASK Type a query or URL vid-cli "query"
  2. →
  3. 02 · PICK Choose in fzf ENTER or TAB + ENTER
  4. →
  5. 03 · RESOLVE yt-dlp finds the stream -f "height<=720" -g
  6. →
  7. 04 · PLAY mpv takes over direct video + audio URL

--anime

Anime data from AniList. Streams from the services that license them.

Search titles, read the details, and jump to official episodes without a scraper or a mirror in sight.

  • Official episodes: AniList's streamingEpisodes list, with the service name and episode title. YouTube episodes play locally; Crunchyroll, Netflix and other licensed links open in your browser.
  • The full picture: synopsis with HTML stripped, genres, main studio, status, next airing episode in local time, and the official trailer.
  • Polite by default: responses are cached for ten minutes, and an HTTP 429 is retried at most once with a short delay.

No mirrors. No scrapers. No decryption. If a service needs a login or a subscription, that happens on the service's own site. vid-cli does not bypass paywalls, DRM, regional restrictions or age gates.

Usage

All the flags, none of the ceremony.

Run it in place or install it. Every option has a short form and a clear default; -h prints the complete reference.

bash 
vid-cli "lofi hip hop"              # search and play
vid-cli -q 1080 "documentary"       # request 1080p
vid-cli -a "album"                  # audio only in mpv
vid-cli -d "lecture"                # download to ~/Videos/vid-cli
vid-cli --subs=fr "film"            # subtitles if available
vid-cli -c                         # history menu
vid-cli --anime "Cowboy Bebop"      # AniList browser
vid-cli "https://youtu.be/…"       # play a URL directly
-q, --quality360, 480, 720, 1080, best or worst. Default 720.
-d, --downloadSave instead of playing. Combine with -a for audio.
--subs[=LANG]Load subtitles when available. Default en.
--sort MODErelevance, date or views. Date uses YouTube's date filter.
-c, --continueReopen history, newest first.
--animeAniList mode: metadata, trailer and official links.

-h every flag and environment variable -V version -U update instructions, never run automatically

Install

One script. Five required tools.

vid-cli is a POSIX sh script. It checks dependencies at startup, names anything missing, and exits with status 2. It never installs anything by itself.

sh curl jq yt-dlp mpv fzf ffmpeg optional rofi optional vlc optional

Debian / Ubuntu

apt 
sudo apt install curl jq yt-dlp mpv fzf ffmpeg

macOS

homebrew 
brew install curl jq yt-dlp mpv fzf ffmpeg

Arch Linux

pacman 
sudo pacman -S curl jq yt-dlp mpv fzf ffmpeg

Termux

pkg 
pkg install curl jq yt-dlp mpv fzf ffmpeg

Windows — Git Bash

winget 
winget install --id yt-dlp.yt-dlp -e
winget install --id junegunn.fzf -e
winget install --id jqlang.jq -e
winget install --id shinchiro.mpv -e

Run it in place

From the directory that contains vid-cli:

chmod +x vid-cli
./vid-cli "lofi hip hop"

Install it system-wide

Installs the script and the man page. PREFIX and DESTDIR are honoured. On Windows, make is not included with Git Bash; run the script in place instead.

make install
PREFIX="$HOME/.local" make install

Principles

Small on purpose.

No daemon, no database, no account. Just a shell script and the tools you already have.

POSIX sh

Runs under dash, stays clean under ShellCheck, and avoids eval and unsafe expansion.

Plain files

History and AniList cache live under XDG directories. No telemetry, analytics or background update checks.

No bypasses

No paywall, DRM, login, geo or age-gate workarounds. If a video is restricted, vid-cli says so and moves on.

Offline tests

The suite uses fake binaries and a saved AniList response. No network access is required to run it.
